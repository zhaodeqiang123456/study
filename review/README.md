# 408 书面作答

每天 1 题，限时 8 分钟，不看笔记、不查资料，写完再对照复盘。判定标准是面试官能不能听懂你写的东西，不是和教材一字不差。

命名与格式：

- 作答文件：`YYYY-MM-DD-主题.md`，例如 `review/2026-09-22-数组与链表.md`
- 格式用 `templates/408-answer.md`：四段作答（结论 / 原因 / 对比与边界 / 场景）+ 复盘（漏掉的点、含糊的点、面试官追问、一句话版本）

节奏：数据结构（数组、链表、栈、队列）→ 操作系统（进程/线程/内存管理）→ 计算机网络（TCP/IP、HTTP、DNS）→ 第 9-10 月按整场面试出题，书面作答 + 追问复盘。

每篇最后一行的"一句话版本"会沉淀成你自己的复习提纲，复习时只看这一行。
