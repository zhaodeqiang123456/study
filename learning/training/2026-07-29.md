## 3. 算法：最短覆盖连续区间（15 分钟）

```go
func minDistinctWindow(nums []int, k int) int
```

示例：

```text
nums = [1, 2, 1, 3, 2], k = 3  -> 3
nums = [1, 1, 1],       k = 2  -> 0
```
