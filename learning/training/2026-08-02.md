## 1. 错误链诊断（10 分钟）

解释以下代码中哪些判断可靠，并改写不可靠部分：

```go
var ErrNotFound = errors.New("not found")
err := fmt.Errorf("load task: %w", ErrNotFound)
```

分别说明字符串比较、`errors.Is`、`errors.As` 的适用边界。需要学习文档第 1、2 节。

提示入口：先区分“展示文本”和“程序语义身份”。

## 2. HTTP 错误映射（12 分钟）

设计 `mapError(error) (status int, code string)`，至少覆盖未找到、参数非法、冲突、依赖超时和未知错误。写出不应泄漏给客户端的底层信息。需要学习文档第 3、4 节。

提示入口：先定义 API 稳定错误码，再决定底层错误如何归类。

## 3. 重试与幂等场景（10 分钟）

针对 DB 插入、Kafka 发送、查询未找到三种错误，分别判断是否可重试、重试前提和副作用风险。至少给出一个重复写入反例。需要学习文档第 4、5 节。

提示入口：先问操作是否幂等，再问错误是否确定发生在副作用之前。

## 4. 可运行验证（8 分钟）

在 `learning/exercises/basics/` 新增表驱动测试，验证错误包装后的 `errors.Is` 和 HTTP 映射；运行 `gofmt`、目标包 `go test`，保留输出。需要学习文档第 2、5 节。

提示入口：测试表至少包含包装错误、直接错误和未知错误三类。
