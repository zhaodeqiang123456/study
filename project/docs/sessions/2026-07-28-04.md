## 当前最高优先级问题

1. HTTP Handler 在 goroutine 中写 `ResponseWriter`，响应生命周期不可靠。
2. Kafka 消费需要改为手动提交 offset；业务完成前不能提交。
3. 幂等抢占必须发生在 LLM 调用前，否则重复消息会重复调用和计费。
4. Consumer 中异步落库、忽略事务错误，并将已取消的 context 用于 Redis 操作。
5. LLM、Redis、Qdrant 需要统一的超时和取消传播。
6. RAG 入库使用随机 UUID，重复启动会重复写入；应改为稳定内容哈希 ID。
