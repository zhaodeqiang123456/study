2. **VHDX 丢失** → `ext4.vhdx` 在 `D:\tools\` 不存在 → 注销重装
3. **wsl --install 超时** → `raw.githubusercontent.com` 被 GFW 屏蔽
4. **ubuntu-base 下载慢** → `cdimage.ubuntu.com` 太慢 → 清华镜像 2s 下完
5. **Go toolchain 超时** → `proxy.golang.org` 被墙 → `golang.google.cn` 下载二进制

### MSYS 路径转换问题
Git Bash 会将路径从 Unix 格式转换为 Windows 格式再传给 WSL，导致 `wsl: Failed to translate` 错误。

**解决方案**：
```bash
MSYS_NO_PATHCONV=1 PATH="" /c/Windows/System32/wsl.exe -d Ubuntu-26.04 -u zdq -- bash -c "..."
```

### Go 1.26.4 安装方式
不要用 apt 的 golang-go（版本 1.26.0 不匹配 go.mod 的 1.26.4），从 `golang.google.cn/dl/` 下载官方二进制。
